## 🌟 จุดเด่นและสถาปัตยกรรมของระบบ
1. **Frontend สำหรับ Vercel (Static Web App):**
   - พัฒนาด้วยเทคโนโลยี SPA (HTML5, Tailwind CSS, JavaScript Vanilla) โหลดเร็ว ทำงานได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์
   - สามารถ Deploy บน Vercel ได้ทันทีโดยไม่ต้องเชื่อมต่อกับ GitHub (ใช้ Drag & Drop โฟลเดอร์ขึ้น Vercel Dashboard หรือคำสั่ง `vercel deploy`)
2. **ฐานข้อมูล 145 โรงเรียน (Authoritative Master Database):**
   - ฝังข้อมูลทั้ง 145 โรงเรียนใน 14 กลุ่มโรงเรียน พร้อมสถิติจำนวนนักเรียนและขนาดสถานศึกษาจาก Google Sheet ID: `1SixGKrITnWuAW5Ex6qZWVSt6MwhZ0DAO4JVcJRSMAeA`
3. **ระบบกระจายเครื่องมือเฉพาะโรงเรียน (School Hub & Quick Dispatch):**
   - เมื่อโรงเรียนเลือกชื่อโรงเรียน ระบบจะสร้างลิงก์สำเร็จรูปและ **QR Code ประชาสัมพันธ์** ที่ล็อกรหัสโรงเรียนให้อัตโนมัติ
   - ปุ่ม **"แชร์เข้า LINE"** และปุ่ม **"พิมพ์การ์ด QR Code"** ช่วยให้ส่งต่อกลุ่มเป้าหมาย (ครู/นักเรียน/ผู้ปกครอง) ได้ง่ายที่สุดใน 1 คลิก
4. **ชุดเครื่องมือประเมินครบทั้ง 5 ชุด พร้อมเกณฑ์รูบริกส์ (Rubrics):**
   - 1. เครื่องมือสำหรับศึกษานิเทศก์ (10 ตัวบ่งชี้)
   - 2. เครื่องมือสำหรับสถานศึกษา (20 ข้อ + Action Plan)
   - 3. เครื่องมือนิเทศ ติดตามครูผู้สอน (4 องค์ประกอบ 18 ข้อ + สะท้อนคิด)
   - 4. แบบประเมินพฤติกรรมเด็ก EF 9 ด้าน (ปฐมวัย 3-6 ปี & ประถม 7-9 ปี)
   - 5. แบบประเมินตนเองของผู้ปกครอง และการสังเกตพฤติกรรมเด็กที่บ้าน
5. **ระบบแอดมินใหญ่ (Super Admin Center) & คลังสื่อร่องรอยหลักฐาน (Media Hub):**
   - สำหรับ ศน.พุฒิพงษ์ วงศ์นันท์ ในการติดตามสถานะ 145 โรงเรียน
   - **คลังสื่อ ภาพถ่าย และเอกสารแนบ (Media & Evidence Hub):** คลังเรียกดู ค้นหา พรีวิว ขยายภาพ Lightbox และคัดลอกลิงก์/โค้ดภาพร่องรอยการจัดประสบการณ์ Active Learning เพื่อนำไปจัดทำเล่มรายงานและ SAR
   - กราฟใยแมงมุม (Radar Chart) วิเคราะห์ EF 9 ด้าน, กราฟเปรียบเทียบกลุ่มโรงเรียน
   - ส่งออกฐานข้อมูลและสารบัญไฟล์เป็นไฟล์ **Excel (.xlsx)** และพิมพ์รายงานสารสนเทศทางการในรูปแบบ A4

## 🚀 วิธีการนำขึ้นใช้งาน (Deployment Guide)

### ขั้นตอนที่ 1: Deploy หน้าเว็บขึ้น Vercel (โดยไม่ผ่าน GitHub)
1. เข้าสู่เว็บไซต์ [vercel.com](https://vercel.com) แล้วล็อกอินเข้าบัญชีของท่าน
2. ไปที่หน้า **Dashboard** คลิกปุ่ม **"Add New..."** -> **"Project"**
3. ลากโฟลเดอร์ `ระบบประเมิน EF 69` ไปวางใน Vercel หรือใช้ [Vercel CLI](https://vercel.com/docs/cli) พิมพ์คำสั่ง `vercel --prod`
4. เมื่อ Deploy เสร็จ ท่านจะได้รับ URL เว็บไซต์ (เช่น `https://ef69-nan1.vercel.app`) สามารถนำไปเผยแพร่ให้โรงเรียนใช้งานได้ทันที

### ขั้นตอนที่ 2: ตั้งค่า Google Apps Script (บันทึกข้อมูลลง Google Sheet & Drive)
1. เปิด Google Sheet ID: `1SixGKrITnWuAW5Ex6qZWVSt6MwhZ0DAO4JVcJRSMAeA`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. นำโค้ดจากไฟล์ `Code.gs` ไปวางในหน้าต่าง Apps Script
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
5. เลือกประเภท **เว็บแอป (Web app)**:
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้
7. เข้าสู่หน้าเว็บ -> เมนู **"ผู้ดูแลระบบ"** (รหัสผ่าน: `nan1ef`) -> คลิกปุ่ม **"ตั้งค่า Google Sheet Web App"** แล้ววาง URL ดังกล่าว
8. โฟลเดอร์ Google Drive คลังไฟล์: `1nhD1UI4lE6Dox1VrFvKKDS9LbqqV_Y4I`
